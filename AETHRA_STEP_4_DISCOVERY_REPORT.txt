- wakeReadyDependents() only wakes when ALL dependencies are COMPLETED

## TaskEngine.wakeReadyDependents()

## TaskEngine.releasePreparedTasks()

- Handles dependency checking
- Respects maxConcurrent limit
- Starts task via startTaskLocked()

## TaskEngine.drainQueue()

- Checks dependencies before starting
- Respects risk class approval gates

4. EXISTING TASKENGINE PREPARE/RELEASE CONTRACT
================================================================================

## TaskEngine.prepare()
- Creates task with dependsOn list
- Validates dependencies exist in TaskEngine
- Validates no cycle would be created
- Marks task as PREPARED
- Persists immediately

## TaskEngine.releasePreparedTasks()
- Marks tasks as released
- Transitions from PREPARING/WAITING_DEPENDENCY to QUEUED
- Persists
- Calls run() on each task

## TaskEngine.run()
- Idempotent: returns current state if already RUNNING/APPROVED
- Checks if task is EXECUTED or COMPLETED
- Transitions QUEUED/PREPARING → PREPARING
- Checks risk class → WAITING_APPROVAL if SENSITIVE+
- Checks dependencies → WAITING_DEPENDENCY if not ready
- If maxConcurrent reached → APPROVED → QUEUED
- Otherwise → APPROVED → startTaskLocked()

## TaskEngine.prepare() for workflows
- Creates task with workflowId and executionAttemptId
- Marks as PREPARED
- Sets creationContext = "workflow_prepared"
- Does NOT enqueue or start execution

## TaskEngine.releasePreparedTasks()
- Marks tasks as released
- Transitions PREPARING/WAITING_DEPENDENCY → QUEUED
- Calls run() on each task

5. EXISTING WORKFLOW TERMINAL-STATE EVALUATION
================================================================================

## WorkflowEngine.monitorWorkflow()
- Runs in coroutine, polls every 200ms
- Checks if all nodes are terminal
- Checks for failed dependencies
- Determines final workflow state:
  - COMPLETED: all nodes terminal, no failures
  - FAILED: any node FAILED/ERROR, or failed dependency
- Persists final state
- Publishes workflow_completed/workflow_failed event

## Terminal States Checked
- TaskState.COMPLETED
- TaskState.FAILED
- TaskState.CANCELLED
- TaskState.ERROR
- TaskState.OUTCOME_UNKNOWN

## Failure Detection
- hasFailed: any node FAILED or ERROR
- hasFailedDependency: any node has dependency that FAILED or ERROR
- Final state: FAILED if hasFailed OR hasFailedDependency, else COMPLETED

================================================================================
5. EXISTING CANCELLATION BEHAVIOR
================================================================================

## WorkflowEngine.cancel()
- Sets workflow state to CANCELLED
- Cancels all tasks via taskEngine.cancel()
- Persists workflow
- Publishes workflow_cancelled event

## TaskEngine.cancel()
- Cancels task if in RUNNING, PAUSED, WAITING_APPROVAL, WAITING_DEPENDENCY, QUEUED
- Cancels running job
- Removes from running/pending
- Persists
- Calls onTaskTerminal() which calls wakeReadyDependents()

## TaskEngine.cancel() - Important
- Does NOT cascade cancellation to dependents
- Dependents stay in WAITING_DEPENDENCY
- Dependent can be unblocked if cancelled task is retried and succeeds

7. EXISTING RECOVERY BEHAVIOR
================================================================================

## WorkflowEngine.recoverWorkflows()
- Called on init via scope.launch
- Awaits taskEngine.awaitRestored()
- Loads all persisted workflows
- For each persisted workflow:
  - Reconciles via reconcileWorkflow()
  - Validates graph structure
  - Reconciles taskIdMap with TaskEngine
  - If RUNNING: releases prepared tasks, restarts monitoring

## Recovery Behavior
- Reuses executionAttemptId if already set (recovery)
- Increments attemptCounter only on fresh execute()
- Reconstructs tasks via taskEngine.prepare()
- If RUNNING: calls releasePreparedTasks() and restarts monitoring
- Does NOT increment attemptCounter during recovery

## Recovery Idempotency
- Multiple recoveries produce same result
- No duplicate workflows in storage
- executionAttemptId preserved

## Recovery Validation
- Validates graph structure (no cycles, no duplicate IDs, etc.)
- Validates actualTaskId exists in TaskEngine
- Fails recovery if validation fails (returns null)
