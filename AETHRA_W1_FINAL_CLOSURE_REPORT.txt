3. BEFORE/AFTER BEHAVIOR FOR EACH BLOCKER
--------------------------------------------------------------------------------

BLOCKER 1 — TASKENGINE SHUTDOWN
--------------------------------
BEFORE: close() cancelled scope immediately, losing pending persistence writes.
        No tracking of accepted writes. Concurrent close() callers raced.

AFTER:  close() uses ShutdownState machine (Open → Closing → Closed).
        Tracks pending persistence writes in pendingPersistsList.
        Awaits all captured writes via Job.join() before cancelling scopes.
        Releases storage ownership. Concurrent callers share one shutdown result.
        Accepted writes never silently cancelled. Persistence failures observable.

VERIFICATION: All 75 task tests pass, including concurrent close scenarios.

--------------------------------------------------------------------------------

BLOCKER 2 — STORAGE OWNERSHIP
------------------------------
BEFORE: No enforcement. Multiple TaskEngines could share Storage silently.
        No crash recovery for ownership.

AFTER:  StorageOwnershipRegistry enforces single active TaskEngine per Storage.
        tryAcquire() rejects second engine unless first isClosed().
        Ownership released on close(). Crash recovery: new engine can acquire
        if previous owner isClosed(). In-process only (Storage has no CAS).

LIMITATION: Not a cross-process distributed lock. Documented as same-process guarantee.

VERIFICATION: All tests pass. Ownership transfer on close/reopen verified.

--------------------------------------------------------------------------------

BLOCKER 3 — SCHEMA VERSIONING AND MIGRATION
--------------------------------------------
BEFORE: journalKey hardcoded ("aethra.tasks.v1", "aethra.workflows.v1").
        No version field. No migration logic. ignoreUnknownKeys/encodeDefaults only.

AFTER:  PersistedTask/PersistedWorkflow/PersistedWorkflowNode have schemaVersion.
        CURRENT_SCHEMA_VERSION = 1, MIN_COMPATIBLE_VERSION = 1.
        loadAll() throws on version < MIN or version > CURRENT.
        Migration framework ready (identity migration for v1→v1).
        Rejects unknown future versions explicitly. Throws on corrupt data.

VERIFICATION: All persistence tests pass. Corrupt data throws exception.

--------------------------------------------------------------------------------

BLOCKER 4 — DURABLE RECOVERY BEFORE FIRST TASK
-----------------------------------------------
BEFORE: No test proving crash recovery before first Task creation.
        Unclear if executionAttemptId created before or after tasks.

AFTER:  Added crashRecoveryBeforeFirstTaskCreation test proving:
        1. createWorkflow() persists workflow with attemptCounter=0, executionAttemptId=null
        2. Process crash (engine close)
        3. New engine recovers: workflow state QUEUED, attemptCounter=0, executionAttemptId=null
        4. Tasks reconstructed via prepare() in WAITING_DEPENDENCY/QUEUED (not released)
        4. execute() creates FIRST durable intent: attemptCounter=1, executionAttemptId="exec-..."
        5. Recovery does not invent new intent, uses same attemptCounter

VERIFICATION: Test passes. Invariants #4 and #6 demonstrated.

BLOCKER 5 — ATTEMPT UNIQUENESS
-------------------------------
BEFORE: Format "exec-${workflowId}#${attemptCounter}" claimed but not verified.

AFTER:  Format verified: attemptCounter persisted and incremented on execute().
        Unique per workflow per execution attempt. Recovery preserves counter.
