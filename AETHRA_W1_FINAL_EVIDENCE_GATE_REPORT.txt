2. GATE E — STORAGE OWNERSHIP IDENTITY SEMANTICS
================================================================================

ORIGINAL DEFECT:
StorageOwnershipRegistry used `System.identityHashCode(storage)` as map key in `mutableMapOf<Int, Pair<Storage, TaskEngine>>()`.
This is NOT collision-safe: Java permits two distinct objects to have the same identityHashCode.

FIX IMPLEMENTED:
Changed to `IdentityHashMap<Storage, TaskEngine>` which:
- Uses System.identityHashCode for hashing BUT compares keys by object identity (===)
- Is collision-safe: two different objects with same identityHashCode are stored separately
- Keys compared by identity (===), not equals/hashCode
- Guarantees correct behavior even when Storage implementations override equals/hashCode

FILE CHANGED:
  core/src/main/kotlin/org/aethra/core/task/TaskEngine.kt (lines 27-75)
